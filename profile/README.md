Visp Labs builds open tools for coding agents and the systems they ship. Each tool does one job and records evidence you can check, so you don't have to take an agent's word for it.

## For coding agents

| | Project | What it does | Status |
| --- | --- | --- | --- |
| 🧠 | **[Visp&nbsp;Memory](https://github.com/visplabs/visp-memory)** | Project memory for coding assistants. Keeps decisions, warnings and history across sessions and returns them with source citations. | <code>v0.9.0</code> |
| 🛠️ | **[Visp&nbsp;Code](https://github.com/visplabs/visp-coder)** | A harness for AI coding agents. Runs the declared checks, keeps the agent inside its file scope, and has the work reviewed independently. CLI and MCP server. | <code>beta</code> |
| 🔗 | **[Visp&nbsp;Hyper&nbsp;Agent](https://github.com/visplabs/visp-hyper-agent)** | Runs the Visp workflow inside Claude Code, Codex, Copilot or OpenCode. Handles scope, sequencing and evidence; never calls an LLM itself. | <code>experimental</code> |
| 📝 | **[Visp&nbsp;Code&nbsp;Note](https://github.com/visplabs/visp-code-note)** | A linked Markdown knowledge base inside VS Code, with wiki links, tasks and a graph that your agents can query over MCP. | <code>in&nbsp;development</code> |

## For production systems

| | Project | What it does | Status |
| --- | --- | --- | --- |
| 🛡️ | **[Visp&nbsp;DB&nbsp;Access](https://github.com/visplabs/visp-db-access)** | A self-hosted gateway for safe, audited queries against production PostgreSQL and MySQL.
